# HTX Annual Walk & Run 2026 – Leaderboard

Searchable leaderboard with multi-select compare: https://alden000.github.io/AWR26/

## Update the data
```
python htx_lb.py      # download latest standings -> htx_lb.json
python build_html.py  # rebuild index.html from template.html + htx_lb.json
```
The page also has a "Refresh live data" link that loads current standings in the browser.
